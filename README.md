# 客飯廳＋細房 · 平面圖比例修正版 v10

按住滑鼠或手指拖曳旋轉，放手即停；滾輪縮放；Shift＋拖曳或右鍵拖曳平移。
可切換全廳立體、尺寸平面圖、書枱白櫃區、梳化區、電視牆、飯廳、窗邊望返及細房近看。全廳立體與平面圖使用正投影。
加入兩張餐枱及四椅、米色梳化、背後胡桃木半高枱、大型白櫃、電視及矮櫃、四門玻璃展示櫃、主要門口、窗簾、冷氣及大型盆栽；省略雜物及櫃內收藏。
細房保留原有白板藏門、上格床、雙趟門床頭櫃及獨立床架；可操作房門及櫃門，切換122cm客墊模式。
按原平面圖補回入口、廚房及睡房通道分支；黑框玻璃門與白色房門呈垂直轉角。原 A房暫按相片作開放書房，補回工作椅與白櫃前空間。
原圖標示268cm客飯廳闊度、227.5cm飯廳深度及210cm A房闊度；細房保留用戶實量263cm，與原圖的5cm差位分別標示。其他未標示縱向距離按圖比例推算，家私尺寸及地台高度為相片估算。
