# 胡桃木上格床細房 · 3D 佈局參考

[開啟互動3D網站](https://lkw-gif.github.io/walnut-loft-room-3d/)

按住滑鼠或手指拖曳旋轉，放手即停；滾輪縮放。
按「開門外觀」或「關門外觀」查看趟門；可切換日常儲物及客墊模式。
咖啡櫃保留上、中、下三格橫向櫃面。
原有床頭下櫃已加回，改為雙趟門；按「床下櫃」查看，並以獨立控制開啟前／後半格。
兩支床頭承重柱退入櫃側，獨立落地；新增鋼架接駁須由專業人士核實。

網站使用單一獨立HTML檔，Three.js程式及模型均內嵌，不需要登入。
本模型用作佈局參考；標示的假設尺寸及結構細節需要現場確認。
